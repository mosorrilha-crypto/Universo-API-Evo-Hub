# Meta Ads: Diversidade Criativa

## Objetivo

Transformar informações de oferta, público, funil e desempenho em um sistema de criativos **realmente diferentes entre si**, adequado a campanhas Meta com automação de público, orçamento, posicionamento e entrega.

Utilizar para formular uma estratégia e os ativos de decisão. Não prometer resultado, atribuição causal, alcance incremental ou funcionamento determinístico da entrega. Tratar recomendações como hipóteses a validar em testes.

## Princípios operacionais

1. **Partir do criativo, não da hipersegmentação.** Formular mensagens claras para dar ao sistema sinais úteis para teste, mantendo as restrições de audiência que forem legais, comerciais ou estrategicamente necessárias.
2. **Diversificar conceitos, não só acabamentos.** Tratar mudança de cor, cenário, corte, locução ou CTA como variação de produção. Tratar mudança de persona, ângulo, promessa, prova ou mecanismo como novo conceito.
3. **Manter coerência de mensagem.** Alinhar a promessa e o ângulo do anúncio com a página de destino, formulário, catálogo ou conversa de conversão.
4. **Separar função criativa de função de funil.** Não comparar diretamente criativos de descoberta, consideração e conversão como se desempenhassem o mesmo papel.
5. **Decidir com evidência suficiente.** Definir janela de observação, evento de otimização e regra de decisão antes de recomendar escala, pausa ou iteração.

Quando for necessário explicar os fundamentos técnicos e os limites do conceito de Andromeda, consultar `references/fundamentos-e-guardrails.md`.

## Fluxo de trabalho

### 1. Coletar o contexto mínimo

Solicitar ou inferir somente as informações indispensáveis. Registrar lacunas sem inventar dados.

| Campo | Pergunta operacional |
|---|---|
| Oferta | O que é vendido, para quem, com qual preço, condição e prova disponível? |
| Objetivo | Qual evento importa: alcance, visualização qualificada, lead, compra, recompra ou outro? |
| Público | Quais perfis, dores, desejos, objeções e níveis de consciência devem ser explorados? |
| Funil | Qual é o papel da campanha: descoberta, consideração, conversão ou retenção? |
| Destino | Para onde o clique ou a interação leva e qual promessa aparece lá? |
| Ativos | Quais depoimentos, demonstrações, imagens, UGC, especialistas, dados e limitações de marca estão disponíveis? |
| Medição | Quais eventos, janela de atribuição, gastos, período e métricas estão disponíveis? |

### 2. Diagnosticar o gargalo

Classificar o pedido antes de propor soluções. Distinguir entre falta de ideias, baixa diversidade semântica, inadequação de formato, desalinhamento anúncio-destino, fadiga, problema de oferta, dificuldade de mensuração ou falta de volume de dados.

Não atribuir um resultado exclusivamente ao criativo quando houver alterações simultâneas em preço, estoque, landing page, orçamento, público, posicionamentos ou rastreamento.

### 3. Construir a matriz de conceitos

Definir pelo menos três conceitos ao iniciar ou renovar uma campanha. Preencher a matriz abaixo; cada linha deve mudar a **mensagem central**, e não apenas a execução visual.

| Conceito | Persona | Dor ou desejo | Ângulo | Promessa ou mecanismo | Prova | Formato nativo | Etapa do funil | Destino coerente |
|---|---|---|---|---|---|---|---|---|
| C1 |  |  |  |  |  |  |  |  |
| C2 |  |  |  |  |  |  |  |  |
| C3 |  |  |  |  |  |  |  |  |

Usar **persona + ângulo + oferta** como a unidade mínima de conceito. Criar conceitos adicionais quando houver perfis ou objeções materialmente diferentes.

### 4. Escolher a roupagem nativa

Selecionar formato pelo hábito de consumo da persona e pela natureza da prova. Priorizar uma execução que pareça conteúdo útil ou crível dentro do ambiente, sem ocultar que se trata de publicidade quando a plataforma exigir identificação.

| Necessidade de comunicação | Formatos possíveis |
|---|---|
| Explicar ideia ou demonstrar autoridade | Pessoa falando para a câmera, entrevista, corte editorial, tutorial narrado |
| Demonstrar uso ou resultado | Demonstração, unboxing, review, antes/depois permitido, comparação verificável |
| Dar contexto ou reação | React, tela dividida, comentário com fundo, resposta a pergunta frequente |
| Entregar informação escaneável | Carrossel educativo, checklist, nota visual, infográfico simples |
| Construir identificação | UGC autorizado, rotina, bastidores, relato de cliente com comprovação |

Escrever cada roteiro com: gancho específico, desenvolvimento de uma única ideia, prova proporcional à promessa, transição para a oferta e CTA compatível com o estágio do funil.

### 5. Produzir um plano de teste legível

Definir uma hipótese por teste e evitar modificar várias variáveis decisivas na mesma comparação.

| Elemento | Definição exigida |
|---|---|
| Hipótese | Relação testada entre conceito, formato e resultado esperado |
| Variável principal | Conceito, formato, prova, gancho, oferta ou destino |
| Constantes | Evento, oferta, janela, público aplicável e demais elementos mantidos |
| Métrica principal | Métrica conectada ao objetivo de campanha |
| Métricas de diagnóstico | Retenção, CTR, CPC, CPA, taxa de conversão, frequência ou outras pertinentes |
| Janela de observação | Período, gasto mínimo ou volume de eventos necessário |
| Regra de decisão | O que caracteriza manter, iterar, pausar ou escalar |
| Risco de leitura | Mudanças externas, sobreposição, sazonalidade, rastreamento ou amostra insuficiente |

Evitar concluir que CPM, CPC, CTR ou ROAS isoladamente representam sucesso universal. Interpretar a cadeia entre atenção, clique, conversão, valor do pedido e qualidade do cliente quando os dados existirem.

### 6. Analisar desempenho por portfólio

Organizar primeiro por conceito e papel no funil; depois, por formato, prova e gancho. Identificar padrões de saturação e lacunas de cobertura.

Não recomendar pausar um ativo de descoberta apenas por conversão direta fraca sem verificar seu papel no conjunto de campanhas e a qualidade do tráfego que ele inicia. Sinalizar limitações de atribuição e possíveis sobreposições entre campanhas ou canais.

### 7. Entregar uma recomendação acionável

Fornecer, nesta ordem:

1. Diagnóstico em um parágrafo, distinguindo fatos disponíveis de hipóteses.
2. Matriz com conceitos e formatos propostos.
3. De três a cinco briefs ou roteiros priorizados, quando solicitados.
4. Plano de teste com métrica, janela e regra de decisão.
5. Riscos, lacunas de dados e a próxima informação necessária.

## Critérios de qualidade

Revisar antes de entregar. Confirmar que cada conceito é semanticamente distinto; que promessas são sustentadas pelas provas; que não há alegações absolutas, sensíveis ou não comprovadas; que o destino preserva a mensagem do anúncio; e que as regras de decisão não dependem de métricas isoladas ou dados inexistentes.

Para alegações de saúde, finanças, resultados, preços, escassez, depoimentos ou comparações, exigir evidência, qualificação e conformidade com as políticas aplicáveis da Meta e a legislação relevante.
