04 · o que falta, em ordem de prioridade

Lacunas conhecidas

Isso não é "bug" — é trabalho que ainda não foi feito, listado do mais pra menos urgente.

SSE de uma instância só

O aviso em tempo real do painel só funciona enquanto o mesmo processo do servidor está de pé — não sobrevive a restart nem escala pra múltiplas instâncias.

Sem rastreamento de erro

Um erro em produção só aparece se alguém for olhar o log do Render na hora — não existe alerta automático de exceção.

Sem gateway de pagamento

O sistema registra que algo foi pago, mas não cobra ninguém de verdade ainda — é status manual, não cobrança automática.

CRM do operador é só local

OperatorCRM.tsx não fala com o backend — o que é digitado ali fica só no navegador de quem digitou.
