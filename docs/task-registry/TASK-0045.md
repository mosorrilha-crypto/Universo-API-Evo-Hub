# TASK-0045 — troca o link primário do campo de token de gerenciamento pra System User (não expira)

- **Iniciado em:** 2026-08-24T05:13:20.000Z
- **Agente/plataforma:** Claude
- **Issue central:** [#290](https://github.com/mosorrilha-crypto/Universo-API-Evo-Hub/issues/290)
- **Status:** concluída

## Objetivo

Follow-up direto do dono do produto. No TASK-0043 (PR #398), o link primário do campo "Token da Marketing API para gerenciamento" (`TrafficCenter.tsx`) tinha ficado o Graph API Explorer (caminho mais rápido de clicar). Na prática isso não resolveu o problema real: validei o token salvo direto contra a API da Meta (`debug_token`) e confirmei que ele expira poucas horas depois de gerado — e mesmo depois do dono do produto "trocar" o token (reabrir o Explorer e gerar de novo), o valor salvo no banco continuou com o **mesmo** `expires_at`, porque o Graph API Explorer reaproveita a sessão OAuth ativa do navegador em vez de emitir um token realmente novo. Pedido direto: "então troca o link" — trocar qual link é o primário.

## Correção

`src/components/TrafficCenter.tsx`, bloco do campo "Token da Marketing API para gerenciamento": invertida a prioridade visual dos dois caminhos.
- **Link primário agora é o System User** (Business Settings → System Users), com o mesmo destaque visual (ícone `ShieldCheck`, cor indigo) que antes era do Graph API Explorer — é o único caminho que gera um token que não expira, resolvendo o problema de verdade.
- Graph API Explorer virou a opção secundária discreta, rotulada "Teste rápido (expira em horas)" — deixa claro que é só pra teste, não pra produção.
- "Validar token" (Access Token Debugger) continua na mesma linha secundária.
- Removida a chave de copy `generateManagementToken` (Graph API Explorer como CTA principal), que ficou sem uso.

## Achado técnico (não é código, é validação de credencial real)

Validei os tokens de produção direto contra `graph.facebook.com/debug_token` via extensão `http` do Postgres (instalada e removida na mesma sessão, só pra esse diagnóstico — nunca expus o valor do token, só booleans/metadados retornados pela própria Meta): o token de leitura/gerenciamento salvo pro tenant Monique era válido mas expirava em ~1h (token do Graph API Explorer); o token do CAPI (Pixel/Conversions API) é permanente (`expires_at: 0`) — não precisa dessa troca. Ad account `act_677275869339059` confirmado acessível com o token ("Monique Souza", ativa, BRL).
