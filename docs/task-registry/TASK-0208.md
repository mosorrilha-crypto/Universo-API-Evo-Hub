## Objetivo

Botão no painel (Central de Qualidade) pra disparar a avaliação automática do agente sem terminal

## Atualizações

Próximo passo registrado na TASK-0203 (script `npm run eval:agent`, mesmo pedido do dono do produto): disparar a avaliação sem precisar de terminal.

**Refatoração prévia:** extraída a orquestração completa (gerar → rodar no pipeline real → avaliar → registrar falha) do script pra `runAgentEvaluation` (`server/services/agentEvalService.ts`), reaproveitada tanto pelo CLI (`scripts/eval-agent.ts`, agora um wrapper fino) quanto pela rota nova — evita duplicar a lógica em dois lugares.

**Execução em background:** uma rodada de 100 casos leva minutos (cada caso faz várias chamadas Gemini sequenciais), não cabe numa requisição HTTP síncrona. `POST /api/quality-audit/eval-runs` cria um registro de progresso (`agent_eval_runs`, migration `0075_agent_eval_runs.sql`, RLS por tenant igual ao padrão de `system_incidents`) e responde 202 IMEDIATAMENTE com o `runId` — a avaliação continua rodando no processo do servidor via `.then()/.catch()` (nunca `await`), com qualquer erro capturado e gravado em `agent_eval_runs.error` (nunca vira `unhandledRejection`, ver CLAUDE.md). `GET /api/quality-audit/eval-runs` lista as rodadas pro painel fazer polling.

**Frontend:** novo card "Avaliação automática do agente" na aba Visão Geral da Central de Qualidade — campo de quantidade (1-100), botão "Rodar avaliação agora", lista das últimas 5 rodadas com status. Faz polling a cada 3s só enquanto alguma rodada está `running` (para sozinho depois); ao detectar que uma rodada terminou, recarrega a lista principal de reviews automaticamente pra os achados novos (kind=bug) aparecerem sem precisar recarregar a página.
