# TASK-0043 — simplifica os 3 links redundantes do token de gerenciamento na Central de Tráfego para 1 link primário + info secundária

- **Iniciado em:** 2026-08-24T04:35:40.000Z
- **Agente/plataforma:** Claude
- **Issue central:** [#290](https://github.com/mosorrilha-crypto/Universo-API-Evo-Hub/issues/290)
- **Status:** concluída

## Objetivo

Follow-up direto do dono do produto sobre o TASK-0042/PR #397: depois de eu explicar que os 3 links do campo "Token da Marketing API para gerenciamento" (`TrafficCenter.tsx`) — Graph API Explorer, System Users, Access Token Debugger — não eram duplicados entre si (cada um aponta pra um destino diferente), ele questionou corretamente: "se é para obter o mesmo token não precisamos dos três links?". Ele está certo — os 3 links têm destinos diferentes, mas servem o mesmo propósito final (preencher o mesmo campo), e apresentá-los como 3 CTAs de mesmo peso confunde qual clicar. Simplificar.

## Correção

`src/components/TrafficCenter.tsx`, bloco do campo "Token da Marketing API para gerenciamento":
- Mantido só **1 link primário** e visualmente destacado: "Gerar token de gerenciamento na Meta" (Graph API Explorer) — é o caminho mais rápido e o único necessário pra maioria dos casos, no mesmo padrão visual do link de token de leitura logo acima.
- O texto de ajuda do campo (`managementPermissionNote`) ganhou uma frase explicando a diferença prática: o token do Graph API Explorer expira em algumas horas; pra produção, um token de usuário do sistema não expira.
- "Token de usuário do sistema (produção)" e "Validar token" viraram uma segunda linha de texto discreto/secundário (fonte menor, cor neutra), cada um com um link inline curto ("ver guia" / "abrir") — a informação continua acessível pra quem precisar, mas não compete visualmente com a ação principal.
