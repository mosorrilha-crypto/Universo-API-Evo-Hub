No PR #363, lint/test/build passaram, mas dependency review retornou que o recurso não é suportado enquanto o Dependency graph estiver desativado.

1. Em **Settings → Branches**, proteger `main`, exigir o check `lint-test-build`, bloquear force push e exclusão da branch. Não exigir aprovação de uma segunda pessoa ainda, pois não há revisor distinto confirmado.

3. Em **Settings → General → Pull Requests**, habilitar exclusão automática da branch após merge. Limpar manualmente apenas branches antigas claramente associadas a PRs encerrados.
4. O GitHub Project permanece opcional e não deve substituir a issue #290 como painel canônico.
