# TASK-0040 — torna regras de negócio da Base de Conhecimento editáveis inline, sem precisar excluir e recriar

- **Status:** concluída

## Objetivo

Pedido direto do dono do produto (print de tela do painel, seção "Regras de Negócio" da Base de Conhecimento): a lista de regras só tinha botão de excluir — pra corrigir o texto de uma regra existente era preciso apagar e recriar, o que joga a regra pro final da lista (fora da ordem/numeração original), já que `businessRules` é um array simples e "Adicionar Regra" sempre faz `push` no fim.

## Correção

`src/components/AgentKnowledgeBase.tsx`: cada item da lista de regras (seção "2. Regras de Negócio") ganhou um botão de editar (ícone `Pencil`, ao lado do de excluir). Ao clicar, o texto vira um `<input>` inline no lugar do parágrafo, com botões salvar (`Check`) e cancelar (`X`) — Enter salva, Esc cancela. Estado novo: `editingRuleIndex`/`editingRuleText`. `handleSaveEditRule` substitui o texto na mesma posição do array (`businessRules.map`), preservando a ordem/numeração. `handleDeleteRule` foi ajustado pra recalcular `editingRuleIndex` quando uma regra diferente é excluída enquanto outra está em edição (decrementa se o índice excluído for anterior, cancela a edição se for o próprio item excluído) — evita editar a regra errada depois de uma exclusão no meio da lista.
