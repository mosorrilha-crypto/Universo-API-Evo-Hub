## Problema confirmado

como lead. O webhook fromMe da instância Lucas em 15/11/2026 às 08:07:24Z
falhou com messages_pkey ao tentar salvar o mesmo ID global. Recriar Lucas
ou apagar suas mensagens não corrige a recorrência.

## Solução

Mantida a PK global de messages.id. IDs internos Evolution incluem a instância
com componentes codificados e reversíveis. Downloads usam a chave original do
webhook; os objetos de mídia usam o ID interno. O envio de texto retorna o ID
interno e traduz citações de volta ao ID do WhatsApp. A dedupe preserva seu
formato anterior por instância. Registros antigos do próprio tenant são
reconhecidos sem duplicar a bolha; registros de outra empresa não bloqueiam
a gravação. O diagnóstico de histórico reconhece os dois formatos.

Não houve exclusão/recriação de cadastro, migration, alteração de credenciais,
restart ou envio de mensagens reais. O usuário autorizou descartar seus dados
(Lucas), mas não foi necessário usar essa autorização.
