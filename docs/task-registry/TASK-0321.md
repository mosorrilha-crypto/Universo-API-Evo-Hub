# TASK-0321 — Sincroniza theme-color da barra de status/PWA com o tema selecionado (corrige tarja escura acima do cabeçalho claro)

- **Status:** concluído

## Objetivo

Achado real, apontado pelo dono do produto com um print comparando lado a
lado o WhatsApp Business real e o Universo: uma tarja escura aparecia colada
acima do cabeçalho branco do tema claro, algo que o app real não tem.

## Causa raiz

`index.html` (`<meta name="theme-color" content="#111b21">`) e
`public/manifest.json` (`theme_color`/`background_color: #111b21`) fixam a
cor da barra de status do Android/PWA em `#111b21` — que é exatamente
`--surface-panel` do tema **escuro** — de forma estática, sem nenhuma
relação com o tema realmente selecionado no app (`dark`/`light`/`blue`/
`clean`, trocado em runtime via `AppPreferencesContext`). Com o tema claro
ativo, o cabeçalho fica branco mas a barra de status do sistema continua
escura, criando a tarja visível — o WhatsApp real sincroniza a cor da barra
de status com o próprio tema, por isso não tem esse problema.

## Correção

`src/contexts/AppPreferencesContext.tsx`: o mesmo `useEffect` que já grava
`document.documentElement.dataset.theme` agora também atualiza
`document.querySelector('meta[name="theme-color"]')` com a cor de fundo do
cabeçalho de cada tema (mapa `THEME_COLOR`, valores espelhados de
`--surface-panel` de cada tema em `index.css`: dark `#151C22`, light
`#FFFFFF`, blue `#0B2B47`, clean `#FFFFFF`). `index.html`/`manifest.json`
continuam com `#111b21` como valor inicial/de splash screen (usado só antes
do React montar ou durante a instalação do PWA) — não dá pra tornar o
`manifest.json` dinâmico por tema com os padrões atuais de PWA, então essa
cor de splash continua fixa no tom do tema escuro (o padrão da app);
limitação conhecida, documentada, de impacto bem menor que a tarja
persistente que o usuário via durante o uso normal.

## Validação

`npm run lint` limpo. `npx vitest run`: 272 arquivos, 1508 testes, todos
passando (nenhum teste cobria esse comportamento antes; não adicionei teste
dedicado dado o escopo pequeno e a leitura direta do código confirmando a
correção). `npm run build` limpo.

## Pendente/risco

Splash screen do PWA (`manifest.json`) continua fixo em tom escuro
independente do tema — só afeta o instante de abertura/instalação do app
como PWA, não o uso normal (onde o `<meta>` dinâmico já corrige o problema
relatado). Validação visual em dispositivo real ainda não foi feita.
