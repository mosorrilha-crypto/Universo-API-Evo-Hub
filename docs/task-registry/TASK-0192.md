Hoje o código só usa `users/{uid}` (`src/lib/firebase.ts`, `src/components/LoginModal.tsx`), então é uma regra dormente, não uma brecha ativa — mas é uma recomendação de hardening (apertar o catch-all) antes de qualquer uso futuro do Firestore pra dado real.
