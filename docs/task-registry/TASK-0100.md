## Objetivo

Corrigir a normalização de número brasileiro em mensagens recebidas via Evolution, evitando que o mesmo celular forme conversas separadas quando o provedor omite o nono dígito móvel.

## Atualizações

O teste prático autorizado no tenant Monique confirmou que o envio pelo Evolution funciona e que a resposta do celular chega ao banco. O gap foi de identidade: a mensagem enviada usou a chave canônica de celular brasileiro, enquanto a resposta recebida chegou no formato legado de oito dígitos do assinante. Como a conversa é indexada por telefone, isso criou uma segunda conversa para o mesmo contato.

A correção foi aplicada no parser de webhooks Evolution, antes da resolução de tenant, gravação de conversa e automações. A nova função `normalizeConversationPhone` remove formatação e só adiciona o nono dígito em um caso estritamente identificado: país Brasil (`55`), DDD, assinante com oito dígitos e primeiro dígito entre `6` e `9`. Linhas fixas brasileiras e números de outros países são preservados.

Foram adicionados testes para o formato legado, para o formato já canônico, para linha fixa brasileira, para número paraguaio e para a mensagem Evolution recebida sem nono dígito.

A correção é prospectiva. As duas conversas históricas criadas durante o teste permanecerão intactas até uma decisão explícita sobre eventual consolidação de dados, evitando alterar mensagens, etiquetas ou histórico de clientes em produção sem revisão específica.

## Encerramento

**Resultado:** mensagens recebidas via Evolution passam a usar a mesma chave canônica de celulares brasileiros que o envio manual usa, impedindo a fragmentação observada no teste prático.

**Validação:** `npm run lint`; testes focados com 7 cenários; suíte completa com 186 arquivos e 962 testes; e `npm run build`, todos concluídos sem erro.

**Pendente ou risco:** a mudança não migra nem funde conversas históricas. A consolidação de registros já duplicados em produção deve ser uma decisão separada e explícita, pois pode movimentar mensagens e etiquetas entre conversas existentes.
