# TASK-0272 — Unifica as duas barras do header (título+ícones e fileira de abas) em uma única linha na tela de Atendimento

- **Status:** concluída

## Objetivo

Unifica as duas barras do header (título+ícones e fileira de abas) em uma única linha na tela de Atendimento

## Atualizações

Pedido direto do usuário (não veio do backlog de #504), com print comparando as duas fileiras
desktop do header (título+subtítulo+ícones numa linha, abas em outra abaixo, separadas por
`border-t`). Perguntei ao usuário qual abordagem de unificação preferia entre 3 opções — ele
escolheu "uma linha só, título compacto" (logo pequeno + título abreviado sem subtítulo à
esquerda, abas no meio, ícones à direita).

Alterado apenas `src/components/Header.tsx` (bloco desktop, `md:flex`; mobile intocado):
- As duas `div`s desktop (`justify-between gap-5 py-4` com título/ícones, e a `border-t
  ... py-1.5` com as abas) viraram uma única `div` `items-center gap-3 py-2.5`.
- Removido `copy.subtitle` (não cabia mais numa linha só). Logo encolhido de `h-10 w-10`
  pra `h-8 w-8`; título (`h1`) de `text-xl` pra `text-sm`, some em telas `<lg` (`hidden
  lg:block`) — antes era sempre visível em qualquer largura `md+`.
- Botões de scroll das abas (`ChevronLeft`/`ChevronRight`) e o container `overflow-x-auto`
  das abas continuam os mesmos, agora compartilhando a fileira com o título e os ícones
  (`flex-1 min-w-0` no container de abas pra ele ceder espaço primeiro).
- Bloco de ícones (pendências, idioma, tema, senha, perfil, sair) sem mudança de lógica,
  só reposicionado na mesma fileira.

## Validação

- `npm run lint` (tsc --noEmit): limpo.
- `npx vitest run`: 262 arquivos / 1435 testes, todos passando (inclui
  `Header.empresasMenu.test.tsx`, que cobre a navegação desktop).
- `npm run build`: build de frontend (vite) + bundle do servidor (esbuild), sem erros.
- Validação visual manual: subi `vite` local e renderizei `<Header>` isolado (harness
  temporário, não commitado) com os mesmos mocks do teste existente
  (`Header.empresasMenu.test.tsx`: tenant + operador `saas_admin`, todas as capabilities
  habilitadas) via `agent-browser`, screenshots em 1280px. Confirmado: fileira única de
  ~56px, título compacto some corretamente em telas estreitas, abas fazem scroll horizontal
  com os botões de seta quando não cabem todas (esperado com muitas capabilities
  habilitadas ao mesmo tempo), menu "Configurar" abre normalmente na nova posição.

## Pendências/riscos

- Em telas menores que ~1024px de largura (`lg` breakpoint), o texto do título some
  (mantém só o ícone) pra dar mais espaço às abas — mudança de comportamento intencional,
  mas vale confirmar com o usuário se o ícone sozinho é suficiente pra identificar a tela
  em telas médias (ex: laptop 13" com zoom).
- Não alterei o layout mobile (`md:hidden`), que já era compacto e não tinha a duplicação
  de fileiras.
