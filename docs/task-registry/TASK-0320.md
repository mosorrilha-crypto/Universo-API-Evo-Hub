## O que foi entregue nesta rodada (só Atendimento)

- **Bug real corrigido**: a regra de compactação mobile do cabeçalho da
  TASK-0318 (`header.bg-slate-900 { padding-top: ... }`) nunca tinha efeito
  visual — `Header.tsx` define `style={{ paddingTop: 'env(safe-area-inset-top)' }}`
  inline, e estilo inline sempre vence uma regra de stylesheet sem
  `!important`. Corrigido: `Header.tsx` ganhou a classe aditiva `app-header`
  (ao lado das classes Tailwind existentes, nada removido) e a regra em
  `index.css` agora usa `!important` nessa propriedade especificamente.
- **Busca e chips de filtro do Atendimento** (`WhatsAppLeadsSim.tsx`):
  classes aditivas `atendimento-search`/`atendimento-filters`/
  `atendimento-filter`(+`is-active`) nos elementos reais (busca, "Tudo",
  "Não lidos", filtro de janela 24h, filtro de etiqueta) — nada removido
  das classes Tailwind já existentes. CSS novo em `index.css` dá forma
  "pill" total à busca (antes `rounded-lg`) e aos chips, usando
  `--app-search-bg`/`--app-chip-bg`/`--app-chip-active-bg`/`--app-action`
  (tokens da TASK-0318). O chip ativo passou a usar `--app-action` (verde
  mais escuro) + texto branco, batendo com o print de referência (antes era
  `bg-emerald-500`/texto preto do Tailwind puro).
- **Achado real de auditoria, corrigido globalmente**: `divide-slate-700/800`
  (Tailwind `divide-y divide-{cor}`, usado como divisória entre linhas de
  lista) gera um seletor diferente de `.border-slate-800`
  (`.divide-slate-800\/40 > :not([hidden]) ~ :not([hidden])`), então nenhuma
  das auditorias de borda anteriores cobria essas divisórias — ficavam
  cinza-escuro sobre fundo branco no tema claro. Usado em pelo menos 8
  componentes (`WhatsAppLeadsSim.tsx`, `AgendaFinanceiroCenter.tsx`,
  `OperatorCRM.tsx`, `QualityAuditCenter.tsx`, `AdAttributionCAPI.tsx`,
  `FinancialDashboard.tsx`, `TrafficCenter.tsx`, `PublicCatalogSettings.tsx`,
  `SaaSAdminDashboard.tsx`) — corrigido de uma vez pra todos, seguindo o
  mesmo padrão já estabelecido no arquivo pro par light+clean (dark/blue
  não tocados, pois já ficam corretos com divisórias escuras sobre fundo
  escuro).
