## Objetivo

Esconde controles de status do agente pra roles sem permissão (operator/manager)

## Atualizações

**Contexto:** dono do produto logou com credencial de operador e reportou
(print da aba Ferramentas mobile) que conseguiu ver/mexer nos botões de
"STATUS DO AGENTE" (Ativo/Restrito/Pausado/Anúncios), quando operadores
deveriam estar abaixo dessa permissão na hierarquia de roles.

**Investigação (agente Explore):** o backend sempre esteve protegido —
`POST /api/agent-status` (`server/routes/conversations.ts`) já exige
`requireRole('admin')`, e `rbac.ts` confirma a hierarquia
`operator: 0, manager: 1, admin: 2, saas_admin: 3`. O bug real era 100%
frontend: `WhatsAppLeadsSim.tsx` renderizava os pills de status
incondicionalmente, pra qualquer role, em DOIS lugares (faixa fixa desktop
`hidden lg:flex` dentro de `.atendimento-queue`, e dentro da gaveta mobile
"Ferramentas" `toolbarSettingsBody`) — sem nenhuma checagem de
`canManageAgent` (o mesmo gate admin/saas_admin já usado pro tile "Agente &
catálogo" na mesma tela). Pior: `handleChangeAgentStatus` faz uma
atualização OTIMISTA (muda o pill na hora) antes do POST, revertendo só
depois que o servidor rejeita — por isso um operador via o clique "funcionar"
por um instante, mesmo sendo bloqueado no servidor.

**Implementado (`src/components/WhatsAppLeadsSim.tsx`):** ambos os blocos
("Status do agente" fixo desktop + dentro de `toolbarSettingsBody`,
gaveta Ferramentas mobile) agora só renderizam quando `canManageAgent` é
`true` — mesma prop já existente e já calculada em `App.tsx`
(`canSeeAdminTools && tenantCapabilities.agent`, ou seja, admin/saas_admin).
Nenhuma mudança de backend necessária (já estava correto).

**Testes novos:** `WhatsAppLeadsSim.agentStatusPermission.test.tsx` — 2
casos: sem `canManageAgent` os pills/label "Status do agente" não aparecem
em lugar nenhum da árvore; com `canManageAgent` aparecem normalmente.

**Validação:** `npm run lint` (limpo), `npx vitest run` (282 arquivos /
1561 testes, todos passando), `npm run build` (limpo).

**Pendente ou risco:** nenhum identificado — é uma correção puramente de
gating visual, sem mudança de comportamento pra quem já tinha permissão.
