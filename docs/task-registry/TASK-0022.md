# TASK-0022 — reorganizar a aba Empresas SaaS para compactar ações, melhorar tabela mobile e facilitar acesso aos controles

## Objetivo

Reorganizar a aba Empresas/SaaS para compactar ações, melhorar a leitura da tabela no mobile e facilitar o acesso aos controles.

## Atualizações

- Os três botões longos de conexão foram reduzidos a ações compactas — **Meta CAPI**, **Instagram** e **WhatsApp QR** — mantendo tooltip, ícone, foco visível e os mesmos modais/fluxos funcionais.
- A busca e o filtro de segmento foram organizados para ocupar a largura disponível no celular, sem cortar o campo de pesquisa ou o seletor.
- A tabela de tenants agora tem uma apresentação específica para mobile: cada empresa aparece em um cartão compacto com nome, slug/ID, segmento, moeda/idioma, data e status do WhatsApp.
- A tabela completa foi preservada no desktop a partir de `sm`, com rolagem horizontal acessível para larguras menores e todos os dados originais.
- A navegação das subabas foi compactada e continua rolável horizontalmente no mobile.
- Os cartões de métricas e o painel principal perderam espaçamento e sombras excessivos, sem alterar dados reais, permissões, filtros ou endpoints.
