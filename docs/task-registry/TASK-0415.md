## Objetivo

Corrige getPromptAuditView (Auditar Prompt) pra refletir o toggle somente leads na auditoria do prompt

## Atualizações

**Achado**: durante uma auditoria pedida pelo usuário no prompt real do tenant Dr. Daniel Oliveira (que usa `leads_only`, ligado na TASK-0412), o texto de "Auditar Prompt" colado pelo usuário mostrava `O campo "outOfScope" abaixo é sempre false pra este negócio — nunca preencha true.` — o ramo de `buildCachedSystemInstruction` usado quando `leadsOnly` é `false`/`undefined`. Isso contradiz o estado real do tenant (`agent_status.leads_only = true`, confirmado via SQL direto).

**Causa raiz**: `buildCachedSystemInstruction` ganhou o 4º parâmetro `leadsOnly` na TASK-0412, e `generateSpecialistReply` (o fluxo real de geração de resposta) já buscava `isLeadsOnlyMode(tenantId)` e passava adiante — mas `getPromptAuditView` (server/services/autoReply.ts, a função por trás de `GET /api/tenant-prompt-audit`, usada pelo botão "Auditar Prompt" do painel) chamava `buildCachedSystemInstruction(tenantId, agent, fullKnowledgeBaseContext)` sem o 4º argumento, então sempre renderizava o ramo `leadsOnly=false`, quebrando a promessa do próprio docstring da função ("Texto EXATO enviado como systemInstruction... byte a byte igual ao que o especialista real usa").

**Correção**: `getPromptAuditView` agora busca `isLeadsOnlyMode(tenantId)` (mesmo padrão de `generateSpecialistReply`) e repassa pra `buildCachedSystemInstruction`. Adicionado teste de regressão em `conversationsTenantPromptAudit.test.ts` que seeda `agent_status.leads_only=true` e confirma que o `systemInstruction` devolvido contém o texto `Modo "somente leads" está ATIVO` (não o texto do ramo `false`).

**Escopo**: só a função de auditoria (somente leitura, nunca influencia o comportamento real do agente) — o comportamento de produção do `leads_only`/`outOfScope` em si (já ativo desde o deploy de `eb53766`) não muda.

**Verificação**: `npm run lint` / `npx vitest run` (309 arquivos, 1776 testes, incluindo o novo teste de regressão) / `npm run build` — todos limpos.
