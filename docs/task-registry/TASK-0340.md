## Objetivo

Reduz tamanho dos botões da gaveta Ferramentas no mobile (UX: círculos e ícones grandes demais)

## Contexto

Print anotado à mão (pedido direto): os botões da gaveta "Ferramentas" (aba inferior do Atendimento, mobile) estavam grandes demais — círculos de 56px (`h-14 w-14`) com ícone de 20px, grid com `gap-3` entre colunas e `gap-3` entre seções (Status/Idioma/Tema/Anúncios, Módulos, Configurações). Resultado: a gaveta ocupava muito mais altura de tela do que o número de opções justificava, com bastante espaço vazio entre os elementos.

## Mudança

`src/components/WhatsAppLeadsSim.tsx` — só dentro do bloco `renderToolTile`/`toolbarSettingsBody` (linhas ~3667-3986), sem alterar nenhuma outra parte do arquivo:
- Círculo do ícone: `h-14 w-14` (56px) → `h-12 w-12` (48px).
- Ícones internos: `h-5 w-5` (20px) → `h-4 w-4` (16px), em todos os tiles (Status, Idioma, Tema, Somente anúncios, Gatilhos, Vendas, Agenda completa, Financeiro, Crescimento, Configurações e os itens expandidos dela).
- Gap entre ícone e rótulo: `gap-1.5` → `gap-1`.
- Gap entre colunas da grade: `gap-3` → `gap-2` (todas as grades de 4 colunas).
- Espaço vertical entre seções (`border-t ... pt-3`): → `pt-2.5`; sub-grade expandida de Configurações (`mt-3`) → `mt-2`.
- Espaço vertical entre os blocos da gaveta inteira (container `flex flex-col gap-3`): → `gap-2.5`.

Mesma quantidade de opções, ocupando visivelmente menos altura de tela — sem remover nenhuma funcionalidade.
