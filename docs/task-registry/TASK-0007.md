## Atualizações

A varredura encontrou seis jobs periódicos iniciados diretamente com `setInterval`, sem proteção contra bootstrap duplicado nem contra ticks concorrentes no mesmo processo. Foi criado `server/services/periodicJob.ts` com guarda por nome, bloqueio de sobreposição, tratamento seguro de erro e timer `unref`; os jobs de lembretes, follow-ups, alertas e expiração passaram a usá-lo. Também foi endurecido `scripts/start-task.ts` para recusar a geração de novo TASK-XXXX quando o checkout possui alterações ou conflitos, reduzindo o risco de outra colisão como a do TASK-0006. A correção financeira do erro `tenant_004` foi preservada como TASK-0008 e publicada separadamente. A auditoria de dependências encontrou o alerta moderado do `uuid` transitivo via `firebase-admin`; como nenhum código usava o SDK Admin, a dependência órfã foi removida, reduzindo o `npm audit` para zero vulnerabilidades.
