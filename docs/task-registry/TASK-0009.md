# TASK-0009 — investigar erro path-to-regexp no deploy do Render

## Objetivo

Investigar o erro `TypeError: Missing parameter name at index 1: *` observado nos logs do Render e eliminar a incompatibilidade sem alterar as rotas de negócio.

## Diagnóstico

A ocorrência corresponde ao fallback da SPA em `server.ts`, que registrava `app.get('*', ...)`. Essa sintaxe de wildcard literal é incompatível com versões novas de `path-to-regexp` usadas por Express 5, embora o checkout atual ainda use Express 4. A reprodução isolada com a dependência local mostrou que o checkout atual aceita o padrão, portanto a expressão regular é a correção compatível com ambos os parsers e também protege o deploy contra resolução futura para Express 5.

Não foram encontradas outras rotas Express com wildcard literal. O erro acontece no registro da rota durante a inicialização, antes de o servidor ficar disponível; por isso pode gerar `unhandledRejection` no processo de boot do Render.

## Correção proposta

Substituir somente o padrão por `app.get(/.*/, ...)`, preservando o fallback para requisições GET da SPA e evitando a sintaxe especial rejeitada pelo parser novo. O registro TASK-0009 será incluído no mesmo PR da correção.

## Validação prevista

Executar `npm run lint`, `npx vitest run`, `npm run build` e `git diff --check`, além de verificar o CI e o deploy do Render após o merge.
