## Objetivo

Adiciona mapa visual do projeto (HTML) gerado como artifact para consulta rápida de onboarding

## Contexto

O usuário pediu um "mapa explodido" visual do projeto (arquitetura, fluxos,
o que já está ativo) por ser iniciante e achar o repositório grande demais
pra se orientar só pelos docs em texto. Foi gerado como Artifact (HTML
autocontido com diagramas Mermaid do fluxo de mensagem e do fluxo do
painel, tabela de estado real por área e lacunas conhecidas, todos com
conteúdo extraído de `docs/GUIA-DO-PROJETO.md`) e compartilhado com o
usuário. Ele pediu em seguida para adicionar esse mesmo arquivo ao
repositório.

## Mudança

- `docs/mapa-do-projeto/index.html`: cópia do HTML publicado como Artifact
  — página autocontida (CSS + Mermaid via CDN), sem dependência do backend
  da aplicação. Não é servido por nenhuma rota; é pra abrir localmente no
  navegador.
- `docs/GUIA-DO-PROJETO.md`: nova seção "Mapa visual (onboarding)" logo no
  topo, apontando pro arquivo e deixando explícito que é um snapshot
  gerado a partir do próprio guia (2026-09-01/02) — se o guia mudar depois,
  o mapa pode ficar desatualizado até alguém regenerá-lo. O guia continua
  sendo a fonte de verdade, o mapa é só uma visualização derivada.

## Validação

- `npm run lint` (tsc --noEmit).
- `npx vitest run`.
- `npm run build`.
- Revisão manual: HTML é conteúdo estático, sem alteração de código de
  aplicação/rota/lógica de negócio.

## Pendente/risco

- O mapa é um snapshot, não gerado automaticamente a partir do guia —
  qualquer mudança futura no `GUIA-DO-PROJETO.md` (nova fase concluída,
  gap fechado) não atualiza o HTML sozinho; alguém precisa regenerá-lo
  manualmente quando o desalinhamento incomodar.
