## Objetivo

Agenda operacional mais compacta e grade do calendario mais organizada

## Atualizações

Pedido direto do dono do produto, com print da tela circulando duas áreas: (1) o bloco de
métricas + nav de mês + banner "Dia selecionado" no topo da Agenda, pedindo "mais intuitivo e
compacto"; (2) o começo da grade do calendário (nav + cabeçalho dos dias da semana), pedindo
"mais organizado".

- **Bloco do topo (mais compacto)**: o nav de mês (`AgendaFinanceiroCenter.tsx`) já mostrava
  `selectedDateLabel` em texto pequeno abaixo do mês, e logo em seguida um banner separado
  "DIA SELECIONADO" repetia a mesma data + contagem de compromissos + botão "Ir para hoje" — a
  mesma informação duas vezes, em dois cartões empilhados. Fundidos num único cartão: nav de mês
  (‹ mês/ano + dia selecionado + contagem › ) com o botão "Ir para hoje" ao lado, tudo numa linha
  só. Reduz a altura ocupada antes da grade aparecer e elimina a duplicação.
- **Grade do calendário (mais organizada)**: as células vazias antes do dia 1 (quando o mês não
  começa numa segunda-feira — ex: agosto/2026 começa numa sexta) eram `<div />` sem altura, então
  a primeira linha da grade ficava com aparência quebrada/desalinhada comparada às linhas
  seguintes. Agora recebem a mesma altura mínima dos dias reais (`min-h-14`/`sm:min-h-16`, sem
  borda/fundo — só ocupam o espaço), mantendo a grade sempre um retângulo completo.
- 2 testes novos em `AgendaFinanceiroCenter.compactCalendar.test.tsx`: confirma que "Ir para hoje"
  aparece uma única vez e que o banner duplicado "Dia selecionado" não existe mais; confirma que
  as células vazias do início do mês têm a classe de altura consistente com os dias reais.
- Validado com `npm run lint` (limpo), `npx vitest run` (224 arquivos, 1159 testes, todos verdes),
  `npm run build` (limpo). Validação visual via Playwright: como a CDN do Tailwind não tem acesso
  de rede neste sandbox (confirmado via diagnóstico — `ERR_TUNNEL_CONNECTION_FAILED`), usei o CSS
  real já compilado pelo `npm run build` (`dist/assets/index-*.css`, carregado localmente via
  `file://`) para montar um comparativo antes/depois fiel às classes de verdade — confirma o
  cartão único mais compacto sem quebrar layout.
