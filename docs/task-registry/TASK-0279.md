## Objetivo

Rebalanceia UI da lista de conversas: remove barra 'AGUARDANDO CLIENTE' pouco útil e rebaixa destaque do filtro 'Fora das 24h'

## Contexto

Pedido direto do dono do produto, a partir de print da lista de conversas:

> "essa barrinha de aguardando clientes não é muito utiu e o filtro fora das 24hs também não é mais importante que esté dentro das 24hs e precisa de mais atenção"

Dois pontos:
1. A barra de seção "AGUARDANDO CLIENTE" (`WhatsAppLeadsSim.tsx`, grupo `awaitingClient` dentro de `waitingGroups`) não carrega nenhum sinal de urgência/ação — é só "esperando o lead responder" — e ocupava espaço sem utilidade real.
2. O pill de filtro "Fora das 24h" tinha o mesmo peso visual (mesmo estilo de pill sólida, mesmo destaque ao ativar) que "Tudo"/"Não lidos", competindo por atenção com o que de fato precisa de ação agora: as conversas com o cliente esperando resposta há mais tempo, já sinalizadas pelas seções "ESPERANDO HÁ MAIS DE 30 MIN" (vermelho) e "ESPERANDO ATÉ 30 MIN" (laranja) na própria lista.

## Mudança

- **`src/components/WhatsAppLeadsSim.tsx`**:
  - Seção do grupo `awaitingClient` deixou de renderizar a barra de cabeçalho (`waitingGroupMeta.awaitingClient`) — os leads desse grupo continuam listados normalmente, só sem o rótulo/contador em barra. Os grupos `over30`/`under30` (que sinalizam espera real) mantidos como estavam, sem alteração de comportamento.
  - Pill "Fora das 24h" trocado de estilo sólido (igual a Tudo/Não lidos, `bg-emerald-500` quando ativo) para estilo discreto com borda (`border-slate-500`/`border-slate-700/70`, texto acinzentado), reduzindo o peso visual do filtro sem removê-lo — continua funcional e com o contador.
  - Nenhuma mudança de lógica de agrupamento/filtro (`getWaitingGroup`, `isWithin24hWindow`, `windowClosedLeadsCount` intactos) — só apresentação.

## Encerramento

`npm run lint` limpo, `npx vitest run` — 263 arquivos / 1444 testes passando (sem novos testes; mudança é só de apresentação visual, sem lógica nova pra cobrir), `npm run build` limpo.

**Arquivos:** `src/components/WhatsAppLeadsSim.tsx`.
