## Objetivo

Polimento da conversa aberta do Atendimento: remove cartao vazio no topo, composer maior estilo WhatsApp, icone Ficha IA, fonte das mensagens

## Atualizações

Continuação direta da TASK-0163. O dono do produto confirmou "falta apenas alguns ajustes finos" e mandou um comparativo lado a lado com o WhatsApp real (2 telas: Clicpiscinas real vs. Gladys no Universo), apontando:

1. **"ficou um espaço no top"** — investigação encontrou a causa real: o
   "Controls Bar" (`.relative.p-3` logo acima de `.atendimento-chat-shell`,
   com o atalho de Escalonamentos, filtro "somente anúncios", Agenda,
   Ferramentas etc.) nunca era escondido no mobile — só que **todo** botão
   dele já é `hidden sm:flex`/`hidden lg:flex` ou fica dentro de um
   `hidden sm:contents`, então no estado padrão (painel de Ferramentas
   fechado) esse cartão renderizava **vazio** no mobile — só
   padding/borda/sombra, empurrando a conversa pra baixo à toa. Escondido
   agora especificamente quando `!isToolbarSettingsOpen` no mobile (`hidden
   sm:block`); continua visível quando o painel de Ferramentas está aberto
   (é o destino real da aba inferior "Ferramentas", TASK-0147) e sempre
   visível a partir de `sm`, onde a fileira tem conteúdo de verdade.

2. **"ajustar a escala da caixa de texto ... um pouco maior e organizar os
   ícones"** — comparado com o WhatsApp real, ícones/campo/botão de enviar
   estavam menores. Ajustado (`WhatsAppLeadsSim.tsx` + `QuickRepliesMenu.tsx`):
   - Ícones emoji/clipe/respostas-rápidas: 20px → 24px (`w-5 h-5` → `w-6 h-6`).
   - Campo de texto: `text-xs`/`py-2.5` → `text-sm`/`py-3` (fonte e altura
     maiores, mais perto do campo real do WhatsApp).
   - Botão de enviar/gravar áudio: 36px → 44px (`w-9 h-9` → `w-11 h-11`,
     ícone `w-4 h-4` → `w-5 h-5`) — mesma proporção do círculo verde real.

3. **"trocar o icon da ficha ia para um mais adequado"** — ícone de robô
   genérico (`Bot`) não combinava com "Ficha" (registro/perfil do
   contato). Trocado para `IdCard` (lucide-react) na aba inferior mobile
   "Ficha IA" — o texto do rótulo já deixa claro que é IA, o ícone agora
   representa uma ficha de verdade. `Bot` continua importado/usado nos
   indicadores de mensagem "IA vs. Operador", sem mudança ali.

4. **"o tamanho da fonte também pode ser o mesmo do whatsap"** — a bolha de
   mensagem inteira usava `text-xs` (12px); WhatsApp real usa ~14px.
   Trocado pra `text-sm` (14px) no container da bolha (afeta o texto
   principal da mensagem; rótulos de metadado como hora/remetente mantêm
   seus tamanhos menores explícitos, já corretos por design).

Arquivos: `src/components/WhatsAppLeadsSim.tsx`, `src/components/chat/QuickRepliesMenu.tsx`.

- Validado com `npm run lint` (limpo), `npx vitest run` (227 arquivos, 1177
  testes, todos verdes — nenhuma mudança de comportamento, só CSS/ícone),
  `npm run build` (limpo).
- Validação visual via Playwright com emulação de dispositivo de toque real
  (`devices['Pixel 5']`, com meta tag de viewport) e o CSS real compilado:
  confirmado numericamente via `getBoundingClientRect()`/`getComputedStyle()`
  — campo de texto 44px de altura/14px de fonte, botão de enviar 44×44px,
  bolha de mensagem 14px de fonte, e nenhum cartão vazio acima do chat.
