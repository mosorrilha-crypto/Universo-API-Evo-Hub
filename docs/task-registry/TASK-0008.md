## Objetivo

Investigar e corrigir o erro `invalid input syntax for type uuid: "tenant_004"` na consulta financeira.

## Atualizações

A causa foi confirmada no fluxo do `saas_admin`: `activeTenant` começa com o mock local `tenant_004` e `setTenantOverride`/`apiFetch` podiam enviar esse valor no cabeçalho `X-Tenant-Id` antes da hidratação do tenant UUID real. O backend então usava esse valor no `.eq('tenant_id', tenantId)` da rota financeira e o PostgreSQL rejeitava a consulta.

A correção normaliza overrides no cliente e ignora overrides não-UUID no resolver de tenant do backend, usando o tenant do JWT como fallback seguro. Foi adicionado teste de regressão para `tenant_004`; os testes existentes de override passaram a usar UUIDs realistas.

O primeiro push da correção incluiu acidentalmente arquivos de outra tarefa devido a um conflito add/add em `TASK-0006`. Esse commit foi imediatamente revertido no commit `88806a2`; os arquivos removidos foram restaurados. A correção financeira foi reaplicada isoladamente e será publicada em commit próprio.
