3. Menu superior "⋮" (gaveta com Crescimento/Configurar/Empresas/Empresa ativa/Sair/Notificações) eliminado por completo do `Header.tsx` — a linha mobile do cabeçalho fica só com o logo.
4. Todo o conteúdo desse menu migrou para dentro do sheet "Ferramentas" (`WhatsAppLeadsSim.tsx`):
   - "Crescimento" ganhou um tile próprio na grade de Módulos.
   - Nova seção expansível "Configurações" reúne Base de Conhecimento/Catálogo público/Qualidade/Logs do sistema/Disparo em Massa/Empresas — cada item com seu próprio gate de capability, mesmo padrão já usado em outros lugares do app.
