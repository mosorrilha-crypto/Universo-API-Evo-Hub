## Objetivo

Corrige layout do aviso de 24h e adiciona botão de editar/reagendar no card compacto da Agenda

## Atualizações

**Contexto:** dois prints do dono do produto — (1) dentro de uma conversa,
o aviso amarelo "Mais de 24h sem [nome] escrever..." aparecia com o texto
quebrado palavra por palavra, o botão "Sugerir mensagem de retomada" e o X
espremidos ao lado; (2) na Agenda "Hoje" mobile, cada card de compromisso
só tinha o botão "Vincular cobrança" — pedido pra adicionar um botão de
popup pra editar/reagendar o compromisso direto dali.

**Investigação (agente Explore):**
- O aviso de 24h (`WhatsAppLeadsSim.tsx:6012-6038`) era uma única linha
  `flex items-center justify-between` sem `flex-wrap`/`min-w-0` — texto e
  botões brigavam pelo mesmo espaço horizontal, forçando a quebra palavra
  por palavra no mobile.
- O botão de editar/reagendar **já existia** (`EventCard`,
  `AgendaFinanceiroCenter.tsx`, abre o mesmo `AppointmentDialog` em modo
  `'edit'`, que já suporta trocar data/hora via `PATCH
  /api/google-calendar/events/:eventId/reschedule`) — mas só aparecia na
  variante COMPLETA do card (`!compact`), escondido atrás de hover (que
  nem existe em touch). A lista "Hoje"/Pendências (a do print) sempre usa
  a variante `compact`, por isso não tinha nenhum jeito de reagendar
  dali.

**Implementado:**
- `src/components/WhatsAppLeadsSim.tsx` — bloco do aviso de 24h agora
  empilha (texto em cima, botões embaixo) até `sm`, só vira uma linha em
  telas largas o bastante (`flex-col sm:flex-row sm:items-center
  sm:justify-between`), com `min-w-0` no texto pra ele voltar a quebrar
  normalmente por linha, não por palavra.
- `src/components/AgendaFinanceiroCenter.tsx` — `EventCard` (compacto)
  ganhou um botão "Editar/reagendar" sempre visível (sem depender de
  hover), reaproveitando o `setAppointmentDialog({ mode: 'edit', event
  })` já existente — zero código novo de diálogo/API, só expõe o gatilho
  que já estava lá.
- **Corrigido no caminho**: um call site (visão de Mês, dia com 2+
  compromissos) envolvia o card compacto inteiro num `<button>` — com o
  novo botão interno, isso geraria um `<button>` dentro de outro
  `<button>` (HTML inválido). Convertido pra `<div role="button"
  tabIndex={0}>` com o mesmo `onClick`/`onKeyDown`, mantendo a
  acessibilidade sem aninhar botões.

**Testes novos:** `AgendaFinanceiroCenter.compactEditButton.test.tsx` —
clica no botão "Editar/reagendar" do card compacto e confirma que o
diálogo "Editar agendamento" abre.

**Validação:** `npm run lint` (limpo), `npx vitest run` (289 arquivos /
1601 testes, todos passando, incluindo os testes já existentes de
`AgendaFinanceiroCenter.*` e `WhatsAppLeadsSim.reengagementBanner.test.tsx`
sem quebra), `npm run build` (limpo).
