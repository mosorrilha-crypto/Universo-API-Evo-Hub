# TASK-0020 — ajustar separadores de data e não lidas no chat

- **Iniciado em:** 2026-08-23T15:05:49.536Z
- **Agente/plataforma:** Manus.Ai

## Objetivo

Ajustar o histórico do chat para exibir separadores de data no padrão visual do WhatsApp, com suporte a Hoje, Ontem e datas anteriores, sem inventar informação quando o timestamp não for confiável.

## Atualizações

- O badge fixo “Hoje” foi removido.
- O histórico agora insere uma etiqueta central discreta no início de cada grupo de mensagens de uma nova data.
- Timestamps ISO reais são agrupados no fuso local do navegador e formatados em português ou espanhol conforme o idioma da aplicação.
- Timestamps legados no formato `HH:MM` continuam sendo tratados como pertencentes ao dia atual, sem reconstruir uma data histórica.
- Timestamps inválidos não recebem uma data inventada e não geram etiqueta.
- O marcador de “Mensagens não lidas” por posição no histórico não foi simulado: o modelo atual expõe apenas `unreadCount` por conversa e `manuallyUnread`, sem `lastReadMessageId`, `readAt` por mensagem ou fronteira persistida para posicionar a linha corretamente. A contagem/estado de conversa existente foi preservada.
